# Computational Linguistics version

`python artigo/cl/gerar_cl.py` writes `artigo/cl/main.tex` from `artigo/main.tex`.
To compile it, download `clv2025.cls` and `compling.bst` from the journal (https://submissions.cljournal.org/index.php/cljournal/StyleGuide) and put both in this folder.
They are not redistributed here because they belong to the journal.
